# 🌐 How to Hack Web

**How to Hack Web** is a structured web security learning resource focused on understanding modern web technologies, vulnerabilities, penetration testing methodologies, authentication mechanisms, security tools, and defensive security concepts.

This project has been **modified, expanded, and organized by Mahesh Pinjarkar** for learning and practical cybersecurity research.

---

## 🎯 Project Overview

The goal of this project is to provide a structured collection of resources for learning **Web Application Security and Ethical Hacking**.

It covers topics ranging from networking and HTTP fundamentals to advanced web vulnerabilities, authentication, penetration testing, cloud security, and defensive techniques.
